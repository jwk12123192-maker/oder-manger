# 발주서 관리 (Order Manager)

영업 업무용 **발주서 관리 웹앱**입니다. PC와 모바일 브라우저에서 바로 열리는 단일 HTML 파일(`index.html`)로 동작합니다.

## 사용 방법

1. 아래 주소를 브라우저에서 엽니다.
   - https://jwk12123192-maker.github.io/oder-manger/
2. 안드로이드 크롬: 우측 상단 메뉴(⋮) → **홈 화면에 추가** 를 누르면 앱 아이콘처럼 사용할 수 있습니다.
3. 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**.

## 데이터 저장

- 기본은 브라우저 **로컬 저장(localStorage)** 방식입니다.
- PC와 핸드폰의 데이터를 실시간으로 함께 쓰려면 앱의 **설정 → 구글 시트 동기화 URL** 에
  Google Apps Script 웹 앱 주소(`.../exec`)를 넣어 두세요. (스크립트 원본: `google-apps-script.gs`)

## 참고

- 발주서 사진 스캔은 Tesseract.js(OCR)를 사용하며, 선택적으로 Google Gemini API 키를 앱 설정에 넣으면 인식 정확도가 올라갑니다. API 키는 사용자의 브라우저에만 저장됩니다.
- 이 저장소에는 개인 데이터가 포함되지 않으며, 발주 데이터는 사용자의 브라우저/구글 시트에만 저장됩니다.
